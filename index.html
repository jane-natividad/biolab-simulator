BioLab Simulator: run growth experiments, compare scenarios, and see why the curves differ

Jane Natividad  ·  jane-natividad.github.io  ·  View on GitHub

A virtual bench for a hypothetical probiotic or microbial growth study. Choose fictional strains, set nutrient and environmental assumptions, and run simulated replicates. Then compare against a baseline and explore trade-offs. Everything is built on a logistic growth model with each added effect written out in the model card. It's a tool for reasoning about experimental design, not a prediction of how any real strain behaves.

Model card

Growth equation

Logistic growth, solved numerically with a 4th-order Runge–Kutta step (Δt = 0.05 h): dN/dt = r_eff · N · (1 − N / K_eff)

How nutrients and environment enter (assumptions, not biology)

nutrient factor f_S = S / (Ks + S) (Monod-type saturation; S = nutrient availability index 0–1) condition factor f_E = exp( −(c − c_opt)² / (2·w²) ) (bell curve; c = condition index 0–1) r_eff = r · f_S · f_E K_eff = K · f_S (simple mode) The condition index is deliberately unitless. It is not temperature, pH or oxygen, and moving it doesn't predict how a real strain responds to any of those. Each strain's c_opt and tolerance width w are fictional settings that shape the curve.

Optional advanced mode: nutrient depletion & product formation

dN/dt = r · f_S(S) · f_E · N · (1 − N/K) dS/dt = −(1/Y) · dN/dt (nutrient consumed in proportion to growth; Y = yield) dP/dt = α · dN/dt + β · N (Luedeking–Piret: growth-associated α, non-growth-associated β) Here nutrient is a resource that runs out, so growth can stop below K.

Parameters

N₀ initial population · r baseline growth-rate parameter (1/h) · K carrying capacity · S nutrient availability · c condition index · Ks half-saturation · Y yield · α, β product coefficients · measurement CV · duration · replicates. Population is in arbitrary simulated units (think "×10⁶ cells/mL-equivalent"), not real counts.

What the replicate spread means

The model itself is deterministic. Replicates differ only through simulated measurement variability: each observation is the true value × a log-normal error with the chosen CV. The band shows the spread of simulated measurements, not biological or process uncertainty. With fewer than 5 replicates no band is drawn, because it would mean little.

Estimated vs true growth rate

The "estimated r" is fitted the way a lab often does it: the slope of ln(measured population) against time over the early-exponential window (5–40% of the highest population reached), for each replicate. Even with no noise it comes out below the true r_eff, because growth is already slowing inside that window. That's a real pitfall when estimating rates from logistic data. It sits next to the true r_eff, so you can see how measurement noise and window choice bias an estimate.

What calibration would require

Time-course measurements (for example OD or plate counts) for each real strain under controlled conditions. Fit r, K and (advanced mode) Ks, Y, α, β by nonlinear least squares, with replicate-level error. Then establish a measured relationship between real culture conditions and growth before replacing the unitless index. Finally, validate predictions on held-out experiments.

Why this isn't a prediction

Strains, parameters and response curves are invented. Real microbes show lag phases, death phases, diauxic shifts, inhibition, and responses to the environment that this model leaves out. Treat outputs as illustrations of the model's logic.
"The useful question isn't 'which strain wins?' It's 'which assumption made it win?' Every difference on this page traces back to a growth rate, a capacity, or an assumption you chose, and the comparison panel says which."
